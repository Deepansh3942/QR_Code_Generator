# QR_Code_Generator

This is a simple QR Code Generator built using JavaScript. The project allows users to enter a website link, which is then converted into a QR code in real-time. The application runs on a local server and provides an intuitive web interface for generating QR codes from any URL.

🔧 Features

- Built with vanilla JavaScript
- Generate QR codes from user-provided URLs
- Live preview of the QR code
- Lightweight and fast performance
- Runs on a local development server
